# Hardware do MVP

Dimensionamento do shield/placa de interface e fixture para a NUCLEO-H753ZI.

Estado: estrutura inicial criada em 26/10/2026.

Não há esquema ou PCB prontos. Três termopares, MAX485, nova fonte de corrente e aquecedor exigem dimensionamento. O N1040i tem uma entrada por instrumento; a solução dos três canais ainda precisa ser fechada.

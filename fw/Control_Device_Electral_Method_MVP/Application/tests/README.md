# Testes de lógica no computador

Testes das máquinas de estado, cálculos e contratos, com drivers simulados. Não incluir estas fontes na imagem STM32.

Estado: estrutura inicial criada em 26/10/2026.

Testar sequência segura, falhas, dados vencidos, cancelamento, perda de comunicação e persistência parcial. Importar casos da POC somente depois de revisar premissas de hardware e protocolo.

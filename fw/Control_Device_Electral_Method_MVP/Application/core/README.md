# Lógica das sessões

Máquinas de estado e matemática de calibração/ensaio TSP, sem dependência direta da interface web ou da IHM.

Estado: estrutura inicial criada em 26/10/2026.

## Implementações previstas

Estado do dispositivo, calibração elétrica, ajuste de temperatura, execução por patamares, captura TSP e validações. O elemento termossensível acessível das memórias DDR5/LPDDR5 ainda precisa ser confirmado. Não transportar automaticamente correntes ou limites da POC.

## Manutenção

Implementações futuras devem manter as responsabilidades desta camada e atualizar este README com os arquivos efetivamente criados. Arquivos de outras gerações não devem ser copiados sem revisão de interfaces e premissas.

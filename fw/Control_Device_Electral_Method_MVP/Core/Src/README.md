# Fontes geradas

Destino de main.c, MSP, handlers, system/syscalls e suporte da biblioteca C.

Estado: estrutura inicial criada em 26/10/2026.

A entrada deverá inicializar a aplicação uma vez e executar seu serviço periódico; a execução será sem RTOS, em superloop cooperativo com máquinas de estado e serviços de duração limitada.

## Manutenção

Implementações futuras devem manter as responsabilidades desta camada e atualizar este README com os arquivos efetivamente criados. Arquivos de outras gerações não devem ser copiados sem revisão de interfaces e premissas.
